孤岛工坊：微工小记 —— 使用说明
版本 v1.18.0

================================================================
一、这是什么
================================================================
一套 Minecraft 1.21.1 / NeoForge 的【空岛】孤岛工坊，共 84 个 MOD。

默认世界类型是「Skyblock」：创建世界时世界类型默认选中空岛，
主世界 / 下界 / 末地 三个维度全部是虚空，没有地形。

不包含游戏本体、Java 运行环境、启动器，这些需要你自己准备。

收录内容：
  · Mekanism 及扩展（发电机 / 工具 / 附加 / 激光）
  · Oritech、Energized Power、Just Enough Mekanism Multiblocks
  · Applied Energistics 2（含无线终端、GuideME）、Refined Storage 2
  · Immersive Engineering、Powah、Extreme Reactors、EnderIO、Industrial Foregoing
  · Pipez、XNet、RFTools Base、Actually Additions、CC:Tweaked
  · Functional Storage、Storage Drawers、Sophisticated Storage / Backpacks
  · Oritech、Energized Power、Just Enough Mekanism Multiblocks
  · 空岛：Skyblock Builder + LibX + Default World Type
  · FTB：Quests、Library、Teams、Ultimine、Chunks、Essentials
  · 便利玩法：Squat Grow（蹲起催熟）
  · 性能优化：Sodium + Iris、ModernFix、FerriteCore、EntityCulling、
    ImmediatelyFast、Noisium、Dynamic FPS、Particle Core、Clumps、
    AI Improvements、Fast IP Ping、Spark、Chunky
  · 中文体验：IMBlocker（游戏内输入法）+ JustEnoughCharacters（拼音搜索）
  · 体验：JEI、Jade、Mouse Tweaks、AppleSkin、
    Toast Control、Crafting Tweaks、Controlling、BetterF3、Searchables、
    Carry On、Corpse、Waystones、Curios、Inventory Profiles Next

三、三种用法，挑一种就行
================================================================
【用法 A】导入 .mrpack —— 推荐，最省事
  用 Prism Launcher / MultiMC / Modrinth App / HMCL 的「导入整合包」，
  选择 Lone-Isle-Works-1.21.1-NeoForge.mrpack，启动器会自动装好 NeoForge、
  下载全部 MOD 并逐个校验哈希。

【用法 B】双击 一键下载MOD.bat
  把整个文件夹拷到任意位置，双击运行。它会在本目录生成 mods\，
  逐个下载并用 sha1 校验；中途失败直接重跑，已下好的会自动跳过。
  然后把 mods\ 里的 .jar 全部拷进 mods\ 目录。

【用法 C】packwiz
  packwiz\ 是标准 packwiz 包：packwiz install packwiz\pack.toml

四、空岛怎么玩起来
================================================================

【起始岛给什么】
出生岛上有一棵橡树和一个箱子，箱子里一共 27 格物资：

  原版空岛自举（Skyblock Builder 自带）
      冰 ×1、岩浆桶 ×1、沙子 ×32、西瓜片、南瓜种子、
      甘蔗、仙人掌、竹子、黑曜石 ×10
      冰化成水 + 岩浆 = 无限圆石，这是空岛的根基

  本包追加的科技起步物资
      铁锭 ×64、铜锭 ×64、金锭 ×32、煤 ×64、红石 ×64
      青金石 ×32、钻石 ×8、皮革 ×16、线 ×16
      橡树苗 ×4、面包 ×32、桶 ×2
      锇锭 ×64、锡锭 ×32、铅锭 ×32、钢锭 ×16、铀锭 ×16
      原子重构器透镜·矿工 ×1

  皮革是特意给的：空岛的世界生物群系只有海洋，牛不会刷新，正常途径
  拿不到皮革。没有皮革就做不出书，附魔台和书架会整条断掉。

【资源从哪来】
  空岛没有矿脉。三条产矿路线都在包里：
      1. Actually Additions —— 原子重构器 + 矿工透镜，把石头转化成矿石
         （箱子里已经给了透镜，机器自己造，这是最快的一条）
      2. Industrial Foregoing —— 激光钻井，需要基座和大量能量
      3. Mekanism Lasers —— 矿石生成器，是多方块结构，就地搭建

【药水不会断】
  Skyblock Builder 默认会在下界生成【下界要塞】，所以烈焰人刷怪笼和
  地狱疣仍然拿得到，酿造系统完整。末地主岛也保留。

【三个维度】
  主世界：虚空 + 出生岛    下界：虚空 + 下界要塞    末地：虚空 + 末地主岛
  配置文件在 config\skyblockbuilder\
  注意：起始岛模板只在【新建世界】时生效，老世界不会变。

五、实用功能：输入法 / 拼音搜索 / 连锁采集 / 蹲起催熟
================================================================

【连锁采集 —— FTB Ultimine】
  按住 FTB Ultimine 的功能键不放，再正常挖掘任意方块，就会一次性
  挖掉整条矿脉 / 整棵树。
  功能键在「选项 → 控制 → 按键绑定」里搜 "Ultimine" 即可看到和修改。
  支持按方块类型限制（比如只连锁同种矿石），可在 FTB 的设置界面里调。

【游戏内输入法 —— IMBlocker】
  Minecraft 在 Windows 下有个老问题：打字时候选框内容和游戏窗口的输入焦点对不上，
  经常出现「选了字但框里看不到中文」。IMBlocker 专门修这个，它做四件事：

      · 根据当前场景自动切换输入法状态
        （走路 / 挖矿时自动用英文，打开聊天框才允许中文，
          不会再出现按 WASD 结果打出一串拼音的情况）
      · 聊天框里检测到你在打指令（以 / 开头）时，临时切回英文
      · 让系统输入法的候选框跟随游戏里的光标位置，不会飘到屏幕角落
      · 把输入法的候选内容直接渲染进游戏窗口内部

  最后一条是关键：它不依赖系统输入法在那个小窗口里画字，
  而是由模组自己画，所以在全屏模式下也能正常看到候选字。

  纯客户端模组，服务端不需要装，也没有任何需要手动配置的项目。

  如果仍然看不到候选字，先检查这两点：
      1. 用「窗口模式」而不是全屏（很多系统输入法在全屏下会失灵）
      2. 确认系统里装了至少一个中文输入法（微软拼音即可）

  备选方案：如果 IMBlocker 在你机器上效果不好，可以换成
  ContingameIME-Neo（Modrinth 上的 kitsuneime），它专门为全屏模式设计，
  但下载量和维护活跃度都不如 IMBlocker。
【拼音搜索 —— JustEnoughCharacters】
  Chinese players 的刚需：不用切输入法，直接在搜索框打拼音就能找到东西。
  例：打 "tie" 能搜到所有铁相关物品，打 "men" 能找到各类门。
  支持的范围不只是 JEI：
      · JEI 的物品搜索框
      · AE2 的 ME 终端搜索框
      · REI / EMI（本包没装，但装了也会自动生效）
  它同时支持全拼、首字母、以及模糊音，比如 "hgj" 能匹配到"合金"。
  纯客户端模组，服务端不需要装。也不需要任何配置，装上就生效。
【蹲起催熟 —— Squat Grow】
  对着农作物反复按潜行键（Shift），植物就会加速生长，不需要骨粉。
  默认作用范围和触发概率可以在 config\squatgrow-common.toml 里调，
  支持白名单 / 黑名单指定哪些植物生效，最大作用范围 16 格。
  它还提供一个「按住 Shift 就持续生效」的模式，默认关闭。

六、装完还要做两件事
================================================================
  1. 分配内存：科技包建议 6~8 GB，在启动器 JVM 参数里加  -Xmx8G
  2. 第一次启动会比较慢（ModernFix 要建缓存、Sodium 要编译着色器），耐心等

  想上光影：本包已含 Iris，把光影包丢进 shaderpacks\ 就行。

================================================================
七、出问题怎么办
================================================================
  · 启动崩溃
      先用启动器把 NeoForge 换成 21.1.209 再试一次（最新版偶发不兼容）
  · 某个 MOD 报错
      把 mods\ 里对应的 .jar 移出去，再启动确认，能定位到具体是哪个
  · 卡顿
      视频设置里渲染距离降到 8~10，模拟距离降到 6
  · 想知道是谁在拖后腿
      聊天栏执行  /spark profiler start

  · 不想玩空岛了，想恢复原版世界类型
      删掉 config\defaultworldtype\client-config.toml 即可。
      或者把该文件里的 allowed-world-types 清空、
      world-preset 改成 "minecraft:normal"。

  · 重要：不要单独升级 Sodium
      Iris 1.8.12 只兼容 Sodium 0.6.13，升到 0.8.x 会在进入世界时崩溃。
      这两个 MOD 必须成对升级，见第十节更新记录。

八、关于 FTB 的来源（重要）
================================================================
本包 84 个 MOD 里，有 6 个 FTB 模组不是从 Modrinth 下载的：

  ftb-library 2101.1.37 / ftb-teams 2101.1.11 / ftb-quests 2101.1.36
  ftb-ultimine 2101.1.15 / ftb-chunks 2101.1.22 / ftb-essentials 2101.1.10

FTB 官方只把模组发布在 maven.ftb.dev，不上 Modrinth。所以这 6 个的
下载地址指向 FTB 官方 maven，哈希值是本地下载后计算、
并与 maven 官方发布的 .sha1 逐一比对过的。

影响：
  · 一键下载MOD.bat 走 curl，maven.ftb.dev 能直连，不受影响
  · 部分启动器在导入 .mrpack 时，会提示这些文件「不是来自 Modrinth」，
    这是正常的，允许即可
  · 如果某个网络环境访问不了 maven.ftb.dev，就改用【用法 B】的 .bat，
    或者手动从 https://maven.ftb.dev/releases/dev/ftb/mods/ 下载

另外，FTB Quests 目前是空的（没有任何任务）。任务线内容需要单独制作，
最靠谱的做法是在游戏里用 FTB Quests 的编辑模式（默认 Ctrl+E 打开编辑）
点出一版，导出 config\ftbquests\quests\ 后再分发。

十二、任务线（FTB Quests）
================================================================
本包内置一条给纯萌新的任务线，打开方式：背包左侧的书本图标。

  第一章 · 平平无奇的开头（7 个）—— 经典空岛开局
  第二章 · AE2 储存与自动化（14 个）—— 把箱子变成一个能搜索的网络
  第三章 · 通电！Mekanism 起步与 AE2 自动化（14 个）
  第四章 · 自己造矿，告别资源焦虑（8 个）
  第五章 · 把产能堆起来（6 个）
  第六章 · 便利与终局（6 个）
  支线 · Refined Storage（4 个，可做可不做）

合计 59 个任务。

解锁规则：上一章的任务全部完成后，才能开始下一章。
每一章内部是「若干任务并行 + 闸门任务汇总」，不会一条线卡着你，
想先做哪个都行。

每一关都写了「为什么」——不是告诉你合成什么，而是这东西解决了
什么问题。面向没接触过科技模组的玩家。

重要：虚空世界挖不到赛特斯石英、下界石英、黄铀，
AE2 和反应堆要用的这些材料全部由任务奖励发放。
所以任务奖励不是可有可无的彩头，而是推进流程的必要补给，
请务必领取。
【任务书配图（重要：要手动启用一次）】
本包附了 5 张配图，挂在章节画布上，和任务格子并排显示。
涉及产线或多方块结构的任务，描述里会写「看左边的图【xxx】」：

  基础供电链         第三章   实机截图：发电机 → 能量立方 → 机器的接法
  Mekanism 起步      第三章   实机截图：一排起步机器
  AE2 自动合成布局   第三章   实机截图：合成 CPU 与供应器/装配室
  三条产矿路线       第四章   示意图：虚空世界弄到矿的三条路
  极端反应堆剖面     第五章   示意图：多方块最少要放哪些部件

前三张是本机实机截图，版本绝对正确；后两张是自绘示意图，
因为对应的多方块在游戏里查不到现成结构图。

图片放在 resourcepacks\孤岛工坊图示\ 里，是一个资源包。
导入整合包后请启用一次：
    选项 → 资源包 → 把「孤岛工坊图示」移到右侧 → 完成
不启用的话，任务书里那些位置会是空白（任务本身不受影响）。
【新增的三个模组】
建筑手杖 —— Construction Wands Revived
    拿在手上对着方块右键，会沿着你面对的那一面连续放置。
    按住 CTRL 可以切换核心和选项（建造 / 天使 / 破坏），也能撤销。
    石、铁、钻石、下界合金四档，越高级一次放得越多（最多 1024）。

创造飞行 —— Flight Rings
    两个戒指，戴上就能像创造模式一样飞，摘下来立刻失效。
    基础版便宜、前期就能做，但有饥饿惩罚；
    纯净版贵一些，无限耐久、惩罚轻。想飞又不想等到第八章，就先做基础版。

自动汉化 —— I18nAutoUpdateMod
    首次启动会从 CFPA 汉化源下载简体中文资源包并自动加载，
    物品名、提示、大部分模组界面都会变成中文。
    注意：AE2 的指南书正文（按 G 打开的那个）是独立的 markdown 文件，
    不在汉化包的覆盖范围内，可能仍然是英文。
